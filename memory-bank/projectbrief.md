# Pizza Restaurant Website - Project Brief

## 프로젝트 개요
Next.js 기반의 피자 레스토랑 웹사이트로, 반응형 디자인과 현대적인 UI/UX를 제공합니다.

## 핵심 요구사항
- **메인 페이지**: 자동 슬라이드 배너, 메뉴 프리뷰, 매장 정보
- **메뉴 페이지**: 이미지 슬라이드와 줌 애니메이션, 자동 전환
- **위치 페이지**: 매장별 이미지 갤러리, 지도 연동
- **About 페이지**: 브랜드 스토리
- **반응형 네비게이션**: 데스크톱/모바일 지원, 언어 전환 기능

## 기술 스택
- **Frontend**: Next.js 15, React 19, TypeScript
- **스타일링**: Tailwind CSS, ShadCN/UI
- **패키지 매니저**: pnpm
- **애니메이션**: Framer Motion
- **아이콘**: Lucide React

## 브랜드 컬러
- Primary: `#fc492d` (빨간색)
- Secondary: `#634d40` (브라운)
- Background: `rgba(245, 240, 230, 0.95)` (베이지)
- Accent: `#fd735a` (오렌지)

## 현재 상태
프로젝트는 기본 기능이 완성된 상태이며, 다음 요소들이 구현되어 있습니다:
- ✅ 헤더 네비게이션 (언어 전환 KO/EN 포함)
- ✅ 메인 페이지 이미지 슬라이더
- ✅ 메뉴 페이지 자동 슬라이드 + 줌 애니메이션
- ✅ 위치 페이지 COEX/D-Tower/Humphreys 매장 이미지
- ✅ 반응형 모바일 메뉴
